# genesis-kit

`genesis-kit` — это набор UI-виджетов и мини-игр на React + TypeScript. Репозиторий собран как коллекция независимых модулей: каждый виджет живёт в собственной папке и экспортируется через локальный `index.ts`.

## Что есть в репозитории

### Виджеты продуктивности

- **DateWidget** — карточка с текущей датой, временем и компактным календарём недели на русском языке.
- **Pomodoro** — набор Pomodoro-виджетов трёх размеров с фазами фокуса, короткого и длинного отдыха.
- **StickyNote** — заметка с форматированием текста, переключением цветовых тем и сохранением содержимого.

### Игры и интерактив

- **GameWidget** — большой игровой центр с несколькими встроенными играми: шахматы, шашки, уголки, сапёр, морской бой, пятнашки, змейка, тетрис, реверси и «Пульсик».
- **Dino** — аркадный раннер с котом, вдохновлённый офлайн-игрой из браузера.

## Структура проекта

```text
.
├── date/
├── game-center/
├── pomodoro/
├── runner/
└── sticker/
```

Каждая директория содержит основной компонент, типы, стили и вспомогательную логику.

## Модули

### `date/`

Компонент `DateWidget` показывает:

- число, месяц и год;
- название текущего дня недели;
- строку недели с подсветкой текущего дня;
- текущее время с обновлением по минутам.

```tsx
import { DateWidget } from "./date";

export function App() {
  return <DateWidget />;
}
```

### `pomodoro/`

Папка экспортирует:

- `PomodoroMinor`
- `PomodoroImportant`
- `PomodoroMajor`
- `usePomodoro`
- `useChime`
- UI-элементы таймера и константы фаз

Особенности:

- цикл работы и перерывов;
- автоматическое переключение фаз;
- звуковой сигнал через Web Audio API;
- отдельные варианты размера для разных зон интерфейса.

```tsx
import { PomodoroImportant } from "./pomodoro";

export function App() {
  return <PomodoroImportant />;
}
```

### `sticker/`

Компонент `StickyNote` — это rich-text заметка с `contentEditable`-редактором.

Возможности:

- жирный, курсив, подчёркивание и зачёркивание;
- списки;
- подсветка текста;
- сохранение заметки по `storageKey`;
- переключение цветовой схемы;
- очистка содержимого.

```tsx
import { StickyNote } from "./sticker";

export function App() {
  return <StickyNote size="minor" storageKey="my-note" />;
}
```

### `runner/`

Компонент `Dino` — canvas-игра с несколькими пресетами размера:

- `minor`
- `important`
- `major`

Поддерживает:

- запуск, перезапуск и игровой цикл;
- клавиатурное и touch-управление;
- счёт, рекорд и нарастающую сложность;
- отрисовку препятствий, частиц и декоративного окружения.

```tsx
import { Dino } from "./runner";

export function App() {
  return <Dino size="important" />;
}
```

### `game-center/`

`GameWidget` объединяет несколько игр в одном интерфейсе. Подходит для большой карточки или отдельного игрового экрана.

Список игр:

- шахматы;
- шашки;
- уголки;
- сапёр;
- морской бой;
- пятнашки;
- змейка;
- тетрис;
- реверси;
- «Пульсик».

```tsx
import { GameWidget } from "./game-center";

export function App() {
  return <GameWidget />;
}
```

## Экспорты

Все модули уже имеют локальные точки входа, поэтому импорт можно строить по папкам:

```tsx
import { DateWidget } from "./date";
import { GameWidget } from "./game-center";
import { PomodoroMajor } from "./pomodoro";
import { Dino } from "./runner";
import { StickyNote } from "./sticker";
```

## Для кого этот набор

Репозиторий подойдёт, если вам нужны:

- готовые виджеты для dashboard или desktop-like интерфейса;
- встраиваемые мини-игры в React-приложение;
- компактные независимые компоненты, которые можно подключать по отдельности;
- база для дальнейшей стилизации и адаптации под собственный дизайн.

## Что можно улучшить дальше

Если захотите развивать проект, логичными следующими шагами будут:

1. добавить корневой `package.json` и инструкции по запуску;
2. оформить единый публичный API из корневого `index.ts`;
3. добавить скриншоты и Storybook/документацию примеров;
4. покрыть игровые движки и хуки тестами.
